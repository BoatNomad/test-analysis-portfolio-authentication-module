# QA Portfolio Project — Login & Password Reset Module

This is a sample QA portfolio project focused on testing a login and password reset module.

The goal of this project is to demonstrate practical manual testing skills, including:
- requirements analysis
- acceptance criteria
- test scenarios
- test cases
- bug reports
- test plan
- test summary report
- basic SQL verification queries
- basic REST API test examples
- AI-assisted QA workflow

## Scope

The tested module includes:
- user login
- invalid login attempts
- password reset request
- reset link validation
- password change
- basic security-related cases

## Tools / Concepts Used

- Manual testing
- Test case design
- Bug reporting
- SQL basics
- REST API basics
- Chrome DevTools basics
- AI-assisted test design
