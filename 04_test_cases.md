## TC-001: Successful login with valid credentials

Related scenario: TS-001  
Requirement: REQ-001

Preconditions:
- User has an active account.

Test data:
- Valid email
- Valid password

Steps:
1. Open login page.
2. Enter valid email.
3. Enter valid password.
4. Click "Log in".

Expected result:
- User is logged in.
- User is redirected to dashboard.
